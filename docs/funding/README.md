# Funding — audit grant drafts

The third-party security audit (~$100–200K) is the critical path for HSK
Passport's full mainnet launch. These are **drafts** of grant applications to
fund it. They are not submitted to anyone — submission needs explicit owner
approval and the owner-only details below.

| Draft | Funder | Angle |
|---|---|---|
| [`hashkey-ecosystem-grant.md`](./hashkey-ecosystem-grant.md) | HashKey Chain ecosystem grant | Native infrastructure for the chain; unblocks regulated dApps |
| [`ef-pse-grant.md`](./ef-pse-grant.md) | Ethereum Foundation — Privacy & Scaling Explorations | Public-good ZK identity primitive built on Semaphore v4 |

## Before submitting — owner-only fields to fill

Search the drafts for `{{...}}` placeholders:

- `{{LEGAL_ENTITY}}` — applicant entity / individual name
- `{{CONTACT}}` — contact email / handle
- `{{PAYOUT_ADDRESS}}` — wallet or banking for disbursement
- `{{AMOUNT_REQUESTED}}` — the specific ask (see budget section in each)
- `{{TEAM}}` — team/contributor bios

The technical, impact, and budget sections are grounded in the repo and the
[audit scope](../../audits/external-audit-scope.md); review them but they should
need little change.
